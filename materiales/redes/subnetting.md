# Subnetting

Material de ejemplo para validar el flujo local de búsqueda. Una red se puede
dividir usando máscaras y notación CIDR. Practicar con máscaras, cantidad de
subredes y hosts ayuda a consolidar el cálculo.

## Ruta sugerida

1. Repasar máscaras.
2. Relacionarlas con CIDR.
3. Resolver ejercicios de subredes.
